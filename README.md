# 🛡️ BroShield Antivirus Total - v1.45 Pro

**BroShield** es una solución de seguridad ligera e independiente para Windows desarrollada en Python. Ofrece una interfaz gráfica moderna por pestañas, análisis de amenazas, integración con la API v3 de VirusTotal, monitor activo de procesos y un buzón comunitario para sugerencias.

---

## 🚀 Características Principales

* **💻 Sistema y Escáner Inteligente:** 
  * Análisis rápido de archivos individuales y carpetas.
  * **Examen del Dispositivo:** Escaneo profundo de rutas clave (Escritorio, Descargas, Documentos) con barra de progreso interactiva.
  * **Análisis Heurístico Local:** Detección automática de comandos sospechosos (`PowerShell` oculto, persistencia en Registro, scripts maliciosos).

* **🌐 Protección Web y Escudo de Red:**
  * Comprobación en tiempo real de URLs y dominios mediante VirusTotal v3.
  * **Bloqueo Local:** Opción para bloquear sitios maliciosos modificando el archivo `hosts` de Windows.

* **⚡ Monitor Activo:**
  * Inspección en tiempo real de los procesos en ejecución para verificar la seguridad del sistema.

* **💬 Comunidad y Sugerencias:**
  * Buzón integrado para que los usuarios puedan enviar ideas y sugerencias directamente al desarrollador (guardándose localmente en el Escritorio).

---

## 🛠️ Requisitos e Instalación

### Descarga Directa (Ejecutable `.exe`)
1. Ve a la sección **Releases** (Lanzamientos) en la columna derecha de este repositorio.
2. Descarga el archivo ejecutable: `super_antivirus.exe`.
3. Ejecuta la aplicación. 
   > ⚠️ *Nota de Windows:* Al tratarse de una aplicación independiente y de código abierto sin firma comercial, Windows Defender SmartScreen puede mostrar una advertencia de seguridad la primera vez. Para abrirlo, simplemente haz clic en **"Más información"** y luego en **"Ejecutar de todos modos"**.
